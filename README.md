# FitFlow - Smart Workout Planner

FitFlow is a comprehensive fitness application that helps users plan, track, and optimize their workout routines. Built with React and Node.js, it provides a modern and intuitive interface for fitness enthusiasts of all levels.

## Features

- **User Authentication**: Secure registration and login with JWT tokens
- **Exercise Library**: Browse 50+ exercises with detailed instructions, images, and videos
- **Custom Workouts**: Create and manage personalized workout routines
- **Training Programs**: Build multi-week training programs with scheduled workouts
- **Workout Logging**: Track completed workouts and monitor progress
- **Responsive Design**: Works seamlessly on desktop, tablet, and mobile devices

## Tech Stack

### Frontend
- React 18
- Vite
- React Router
- Tailwind CSS
- Axios
- Lucide React Icons

### Backend
- Node.js
- Express.js
